# commit-triage

A TUI to parse the output of [these commands](https://github.com/servo/servo.org?tab=readme-ov-file#how-to-list-commits-that-landed-in-each-nightly)
and make it less overwhelming to [triage](https://github.com/servo/servo.org?tab=readme-ov-file#triaging-commits-in-nightlies-for-monthly-updates)
the commits that we should write about in Servo's monthly blog updates.

Goals:
* minimize visual distraction
* speed up common investigations
* minimize hand movements
* reduce typos
